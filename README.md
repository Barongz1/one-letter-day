Entry for [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) on make.fun.

`main.py` writes one letter to `/output/entry.txt`:

```
Z
```

Z stands for "zero sleep" — a whole night of bounty hunting.

Run it with:

```sh
python3 main.py
```
